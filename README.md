# OWASP Juice Shop - VAPT Project

## Project Overview
This project documents web application security testing performed in the OWASP Juice Shop training environment.

## Objectives
- Identify common web application vulnerabilities.
- Understand their impact and security risks.
- Document testing evidence and remediation recommendations.

## Vulnerabilities Studied
1. DOM-based Cross-Site Scripting (DOM XSS)
2. Bully Chatbot challenge
3. Admin Login challenge
4. Administration Page challenge
5. Missing Encoding

## Tools Used
- OWASP Juice Shop
- Burp Suite
- Nmap
- Web browser and developer tools

## Methodology
1. Reconnaissance
2. Vulnerability identification
3. Testing in the authorized lab
4. Evidence collection
5. Impact analysis
6. Remediation recommendations

## Disclaimer
All testing was performed in a controlled training environment. This project is for educational purposes only.
